# ANEXTPOST Skill Stack & Pipeline

Active skill stack configured for **ANEXTPOST** (`https://anextpost.com`):

## 1. Content & Social Distribution
- `youtube-growth-and-packaging-master`: Packaging, CTR titles, hooks, and thumbnail A/B testing (YouTube Channel org preset).
- `youtube-publishing-and-monetization-ops`: YouTube encoding, upload, and publishing operations.
- `tiktok-shop-and-social-growth-suite`: 3-second visual hooks, IG carousels, X threads, and LinkedIn growth workflows for Copywriting Studio.
- `viral-explainer-engine`: Scripting and batching 2D explainer content for the Media Library.

## 2. Hosting, Security & Reliability
- `web-seo-and-hosting-suite`: Cloudflare edge/DNS tuning, security headers, Core Web Vitals, and live visual/Playwright QA.
- `backend-infra-testing-and-security-suite`: OAuth2/JWT hardening, Postgres tuning, CI/CD, and observability for 24/7 VPS hosting.
- `mobile-remote-access-suite`: Fast mobile & remote preview workflows while hosting from Mac.

## 3. Desktop, UI & AI
- `electron-desktop-engineering-suite`: Auto-updater, macOS signing/notarization, entitlements, and IPC contracts for `ANEXTPOST.app`.
- `web-design-and-ui-craft-suite`: UI craft across the New Post composer, Calendar, and Copywriting Studio.
- `ai-engineering-and-local-llm-suite`: Structured JSON schemas, evals, and local Ollama pipelines for Rewrite, Check post, and MCP tools.
